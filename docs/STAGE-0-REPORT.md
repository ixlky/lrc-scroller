### 依赖只装了 4 个运行时包

`vue`、`pinia`、`vite`、`@vitejs/plugin-vue`（外加单文件打包插件）。没有 UI 组件库、没有 CSS 框架、没有工具函数库。

**我在选型上做了两处偏离方案的决定，需要你知道：**

1. **Pinia 用 3.0.4，不是最新的 4.0.3**。Pinia 4 强制依赖 TypeScript ≥5.6 和 `@vue/devtools-api`；你要求纯 JS，用 3.0.4 可以完全不装 TypeScript（它的 TS 依赖是"可选"）。
2. **Vite 用 7.3.6，不是最新的 8.3.2**。Vite 8 换成了 rolldown 构建引擎，为降低风险先用成熟版本。后续想升级随时可以。

## 三、过程中发现并修掉的 4 个真实问题

这些都是实测暴露的，不是我"顺手写的"：

1. **dev server 会崩**。Vite 的文件监听在 Windows 上遇到 `scripts/` 里的临时目录抛 `EBUSY` 直接退出。已在配置里排除 `dist/`、`docs/`、`scripts/` 的监听，并限制只监听源码。

2. **`127.0.0.1` 连不上**。Vite 默认只绑 IPv6 的 `::1`，导致 `127.0.0.1:5173` 报 `ECONNREFUSED`——这种问题极容易被误判成"服务没起来"而白折腾。已显式绑 `127.0.0.1`，现在两种写法都通。

3. **播放按钮在触摸设备上只有 38px**（低于 44px 的可点最小尺寸）。它不属于 `.btn`，全局触摸规则覆盖不到，已单独加规则。

4. **我自己的测试有两处写错**，都已修正，并保留了修正说明：
   - 拿"当前行 vs 另一行"比高度——不同行文本折行数本来就不同（实测一行 1 行文本、一行折成 2 行）。正确判定应是**同一行在 scale 变化前后**高度不变，已改成这个更强的断言。
   - 移动端测试忘了开触摸模拟，`pointer: coarse` 不匹配，触摸 CSS 根本没生效，测出来是假象。已加上 `setTouchEmulationEnabled`。

## 四、有意**没有**做的部分

为了不让"看起来完成了"掩盖尚未验证的东西，这些**故意留空**，并且界面上会明确告诉你它们属于哪个阶段：

- **localStorage 持久化与"重置"按钮** → 阶段 3。现在设置只存在于内存，刷新即回到默认值。这样阶段 3 的验收项"刷新后原样恢复"才有真实意义。
- **RGB / HSL 调色盘** → 阶段 3。现在用系统原生取色器，颜色链路（设置 → CSS 变量 → 实际渲染）已经打通并验证。
- **真实音频** → 阶段 2。现在播放条是**模拟播放**，右下角明确标注"阶段 0 · 模拟播放"，避免被误当成已完成。
- **LRC 完整解析** → 阶段 1。`lyricsStore` 里有个仅供演示的最简解析，它**故意不处理**多标签、offset、乱序、编码兜底——那些属于阶段 1 的 `lrcParser.js`，两处实现不互相污染。
- **歌词滚动跟随** → 阶段 3。现在用的是浏览器原生 `scrollIntoView` 打底；阶段 3 会换成 `overflow:hidden` + `translate3d` + rAF，正好在一个还没有滚动逻辑的干净基线上测量"居中误差 ≤2px / CLS≈0 / 2000行 55fps"。
- **临时调试工具**：右下角"阶段 0 预览"的上/下一行按钮是**临时的**，阶段 2 接上音频后即删除。
