## 一、核心诉求达成（实测）

**纯白 `#ffffff` 起点，点绿色 → 变绿；点紫色 → 变紫。不再有"点上去没反应"。**

| 起点 | 点哪 | 得到 |
|---|---|---|
| 纯白 | 120° 边缘 | `#01ff00` 绿 |
| 纯白 | 280° 边缘 | `#ac04ff` 紫 |
| 纯白 | 0/60/120/180/240/300° 边缘 | 红/黄/绿/青/蓝/洋红，均 S≈100% |
| 纯白 | 120° 半径 100% / 50% / 20% | S≈100 / 50 / 20（线性） |
| 纯白 | 正中心 | `#ffffff`（S=0） |
| 纯白 | 死区内（8%） | S 归 0 |

（`#01ff00` 里那 1 级偏差来自我的测试脚本必须补 1px 位移才能触发 `onMove`，非产品问题。）

## 二、四项设计决策的落地

| 你的确认 | 实现 |
|---|---|
| ① 内部换 HSV 作主状态 | `localHsl` → `localHsv`（ref，非 computed）。色轮与明度条**共用同一状态**，拖动路径上**零 HSL↔HSV 往返** |

| ③ S 线性分布 | `S = 100 × r / R` |
| ④ 色轮 120px + 窄屏降级 | 见下节 |

## 四、实现过程中发现的 3 个问题（都写进注释了）

### ① 遮罩洗淡了整个色轮（截图发现）

初版径向遮罩是 `transparent 0% → 50%灰 45% → 灰 100%`，
结果 **45% 半径处就有 50% 不透明灰**，把大半个轮子冲淡了 ——
截图上看起来是一块**白盘**，完全不像色轮（首版 `patch10-wheel-*.png` 已覆盖该问题）。

改为 `transparent 0% → 28% 保持 → 45%@55% → 88%@82% → 100%`：
中心一小块纯色、中段饱和、边缘才褪向灰。

### ② `wheelGradient` 返回对象，Vue 静默丢弃

`ringBackground = computed(() => wheelGradient(v))` 返回 `{ background, center }`，
模板 `:style="{ background: ringBackground }"` 于是变成
`:style="{ background: [object Object] }"` —— **Vue 不报错、不警告，只是不生效**，
表现为「色轮一片空白」。已改为 `wheelGradient(v).background`，并在注释里写明这个坑。

### ③ 明度条水平化后拖动逻辑失效

窄屏降级把明度条改成水平后，原来的 `apply()` 固定读 `clientY`，
**上下拖动完全没反应**。已改为实测轴向（`rect.width > rect.height`）后取对应轴。

### 两条「防假通过」的断言

1. **纯白起点必须真的变色** —— 若拖动没生效，"颜色没变"会同时满足"应该变"和"没变"，断言就废了。所以同时断言**小点 transform 必须变化**。
2. **小点位置读内联样式而非 computed matrix** —— `translate(calc(-50% + 0px), …)` 在 computed 里会算成 `matrix(1,0,0,1,-6,-6)`（12px 的 -50% = -6px），**圆心读出来不是 (0,0)**。这个坑让我误判过一次，断言改为匹配字符串形态。

## 六、保留的修复（按你要求不删）

- **补丁 9 的 `selfEmitted` 修法保留**。色轮下"颜色不变"的情况大幅减少，但**纯黑（V=0）时点色轮颜色仍然不变** → 触发条件依然存在。注释里已写明"不要因为现在不常触发就删掉"。
- **色相记忆**（我自己抓到的细节）：`#ffffff` 反推 HSV 得 `h=0`（红），若小点跟着走，「重置为白色」后小点会跳到红区 —— 视觉像在说"现在是红色"但颜色是白的。解法：`hueMemory` 只由用户拖动更新；`resetToWhite` 把它清零，小点回圆心。
- 对外接口 `modelValue / update:modelValue / invalid` 不变，**`SettingsDrawer` 一行未改**。
- 三件明确不做的事（`--lrc-bg` 主题 / PS 风格调色板 / 保留 HSL 坐标系统）—— 第三条按你"只在 `ensureHueVisible` 内部调整"的要求，**本轮改为 HSV 是你新决策的直接结果**，其余两条未动。

## 八、真机复验清单

**色轮核心**

1. 打开设置 → 颜色 → **当前行颜色**，应看到一个 120px 的**圆盘**（中心灰、边缘彩）
2. 颜色设 **纯白 `#ffffff`** → **点绿色区域 → 字幕变绿**；**点紫色区域 → 变紫** ← 这是本次最该验的一条
3. 依次点红/黄/绿/青/蓝/洋红六个方向（边缘）→ 每种都得到对应纯色，S 滑杆显示 100%
4. 同一色相**从边缘往中心拖** → 颜色逐渐变淡（S 递减），到中心变灰（S=0）
5. **点「重置为白色」** → 颜色回到 `#ffffff`，小点回圆心
6. **明度条**拉到中间 → 色轮中心变成对应的灰（**不是死白**），边缘色相应变暗
7. **联动验证**：明度条拉到最黑 → 点绿色 → 颜色仍黑但**小点已移到绿色角度** → 再把明度条拉回顶部 → **颜色变成绿色**（色相没丢）

9. 鼠标 / 数位板 / 触摸各点几圈
